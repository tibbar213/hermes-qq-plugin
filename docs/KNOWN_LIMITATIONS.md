# 已知限制

- 当前实现仍使用部分 Hermes 内部辅助接口；纯插件表示不改核心文件，不表示跨版本永远兼容。升级需检查提供方、会话、审批、工具注册和子代理接口。
- 通知私聊失败后的回落遵循 Hermes 原生行为，不再具有旧版特殊保证。
- QQ 未下发的嵌套转发内层内容无法读取；消息、按钮、私信和文件权限受 QQ 官方后台及接口限制。
- 沙箱/宿主执行需要 Linux 系统依赖。查询、沙箱与宿主机执行是不同权限层级；模型审核不能自动赋予其他成员宿主 root 权限。
- 执行代理是受信任系统组件，不等于任意恶意插件代码也能被沙箱隔离。普通模型和 JEV 审核均不能替代操作系统权限。
- 异常进程退出仍可能留下任务元数据 running，需要与原生任务状态核对。派发拒绝误记 completed 的问题已经修复。
- 原部署日志脱敏曾不完整；不要提交运行日志、凭据、会话或任务数据。
- 查询文件搜索遇到凭据路径、符号链接或超过 10000 项的目录会要求缩小范围；MCP 工具必须逐项授权。
